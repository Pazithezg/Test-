SOUTH SEEK - ต้นแบบเว็บแอปค้นหากิจกรรมท่องเที่ยวภาคใต้

ไฟล์ในโฟลเดอร์
- index.html  หน้าเว็บหลัก
- style.css   การจัดหน้าตา
- app.js      การทำงานของแอป (ข้อมูลสถานที่อยู่ในตัวแปร D และ INFO, ค่าบริการ 10% และ 7% อยู่ในฟังก์ชัน book)

วิธีเปิดดู
ดับเบิลคลิก index.html เพื่อเปิดในเบราว์เซอร์

วิธีขึ้นเว็บ
อัปโหลดทั้งโฟลเดอร์ไปที่ Netlify (ลากโฟลเดอร์วาง), Cloudflare Pages, GitHub Pages หรือ Vercel
แล้วผูกโดเมนของตัวเองได้ที่เมนู Custom domain

หมายเหตุ
- ราคา คะแนน ผู้ให้บริการ และพิกัดส่วนใหญ่เป็นข้อมูลตัวอย่าง ต้องแทนด้วยข้อมูลจริงก่อนใช้งาน
- ระบบจองเป็นการจำลอง ยังไม่ตัดเงินจริง
- ภาพเป็นภาพวาดประกอบ ยังไม่ใช่รูปจริง
